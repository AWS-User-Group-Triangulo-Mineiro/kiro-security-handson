# Kiro e Segurança — Hands-on

AWS User Group Triângulo Mineiro · Rogério Fontes

Tutorial estático para desenvolver e corrigir uma API Java usando Kiro, Specs, Steering e testes de autorização.

## Abrir
Abra `index.html` no navegador. Não há dependências de front-end.

## Publicar
Envie `index.html` e `README.md` para a raiz da branch `main` de um repositório e habilite Settings → Pages → Deploy from a branch → main / (root).

## Segurança
A versão vulnerável é exclusivamente para execução local. Nunca faça deploy ou exponha o serviço à rede. Use somente credenciais fictícias. Os prompts são instruções de laboratório; os resultados devem ser confirmados executando os testes no ambiente do participante.
